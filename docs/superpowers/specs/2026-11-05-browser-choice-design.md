# Pilihan Chrome dan Firefox

Permintaan lanjutan: tombol Khusus KPPN - Validator Caput membuka dua pilihan versi. Pengguna sebelumnya meminta langsung push dan menjaga tampilan; lanjutkan implementasi dalam lingkup ini.

Gunakan disclosure native details/summary dengan label tombol lama. Isi tertutup pada awalnya, lalu tampil dua tautan unduh Chrome/Edge dan Mozilla Firefox. Memakai token tombol/warna yang ada, tanpa modal atau perubahan mesin validator. Tautan Firefox diberi keterangan pemasangan sementara dan signing belum tersedia.

Chrome ZIP v0.1.3 tetap identik. Paket Firefox terpisah memuat engine yang sama dan adapter browser/port dokumen untuk event-page dan API Promise. Owner dokumen tidak boleh undefined: koneksi port yang hidup menjadi identitas per dokumen, dicabut saat disconnect. Tidak menghilangkan pemeriksaan scope, revisi, deklarasi, fingerprint atau checkpoint submitting.

Firefox diuji dengan instalasi temporer pada profil terisolasi dan fixture sintetis yang menggantikan seluruh request MyIntress. Tidak memakai akun produksi, tidak menonaktifkan signature pada browser pengguna dan tidak mengunggah ke AMO tanpa kewenangan tambahan. Signing permanen memerlukan langkah terpisah.
